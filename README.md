# 📊 Spread Locator | Statistical Data Analysis

### Turning Transaction Data into Statistical Insights

Spread Locator is a Python-based data analytics project focused on exploring transaction patterns using probability, statistical distributions, and data visualization. The project applies statistical concepts to understand transaction behavior and discover meaningful patterns in the dataset.

## 🎯 Project Objectives

- Explore transaction data using statistical methods.
- Understand transaction success and failure patterns.
- Analyze transaction amounts and their distributions.
- Study daily and weekly transaction activity.
- Identify unusual values and high-value transactions.
- Interpret statistical results through visualizations.

## 🔍 Analysis Highlights

- **Probability Analysis:** Examining transaction outcomes and their probabilities.
- **Distribution Analysis:** Exploring Bernoulli, Binomial, Poisson, Log-Normal, and Pareto distributions.
- **Normality Testing:** Applying the Shapiro-Wilk test to examine data distribution.
- **Data Transformation:** Using Box-Cox transformation to study distribution changes.
- **Outlier Analysis:** Using Z-scores to investigate unusual transaction values.
- **Probability Estimation:** Studying the likelihood of high-value transactions.
- **Data Visualization:** Comparing observed data with theoretical statistical distributions.

## ✨ What Makes This Project Valuable?

This project connects classroom statistical concepts with practical data analysis. Instead of relying only on calculations, it uses visualizations and statistical tests to explore the characteristics of transaction data.

It demonstrates the application of probability, distribution fitting, hypothesis testing, and data interpretation in a single analytical notebook.
